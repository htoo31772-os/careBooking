🏥 Clinic Booking System - Project Overviews

ဤ Project သည် ဆေးခန်းများတွင် လူနာများမှ ဆရာဝန်များနှင့် ရက်ချိန်း (Appointment) ယူခြင်းကို Online မှတစ်ဆင့် လွယ်ကူလျင်မြန်စွာ ပြုလုပ်နိုင်ရန် ဖန်တီးထားသော Full-stack Web Application ဖြစ်ပါသည်။

၁။ အဓိက ရည်ရွယ်ချက် (Core Purpose)

လူနာများအနေဖြင့် ဆေးခန်းသို့ တိုက်ရိုက်ဖုန်းဆက်ရန်မလိုဘဲ မိမိတို့ အဆင်ပြေသည့် အချိန်နှင့် ဆရာဝန်ကို ရွေးချယ်ကာ ဘိုကင်တင်နိုင်ရန်နှင့် Admin များမှ စနစ်တကျ စီမံခန့်ခွဲနိုင်ရန် ဖြစ်ပါသည်။

၂။ အဓိက Feature များ (Key Features)

Patient Side (လူနာဘက်ခြမ်း)

Doctor Search: ဆရာဝန်များကို အမျိုးအစား (Category) အလိုက် ရှာဖွေနိုင်ခြင်း။

Booking Flow: အားလပ်သည့် ရက်စွဲနှင့် အချိန် (Time Slots) များကို ရွေးချယ်ကာ Booking တင်နိုင်ခြင်း။

Review System: ဆရာဝန်များကို ကြယ်ပွင့်ပေးခြင်းနှင့် မှတ်ချက် (Comment) ရေးသားနိုင်ခြင်း။

My Bookings: မိမိတင်ထားသော ဘိုကင်များကို ကြည့်ရှုခြင်းနှင့် ပယ်ဖျက် (Cancel) နိုင်ခြင်း။

Admin Side (စီမံခန့်ခွဲသူဘက်ခြမ်း)

Dashboard: စုစုပေါင်း ဘိုကင်အရေအတွက်နှင့် အခြေအနေများကို Overview ကြည့်နိုင်ခြင်း။

Doctor Management: ဆရာဝန်အသစ်များ ထည့်ခြင်း၊ အချက်အလက်ပြင်ခြင်း။

Schedule Management: ဆရာဝန်တစ်ဦးချင်းစီအတွက် အလုပ်ချိန် (Slots) များ သတ်မှတ်ခြင်း။

Booking Control: ဘိုကင်များကို Confirm လုပ်ခြင်း သို့မဟုတ် Cancel လုပ်ခြင်း။

၃။ အသုံးပြုထားသော နည်းပညာများ (Tech Stack)

Frontend: React.js (Hooks, Context API, Tailwind CSS/Bootstrap)

Backend: Laravel (PHP) - RESTful API

Database: MySQL

State Management: Local State & Axios for Data Fetching

Authentication: Laravel Sanctum (Token-based Auth)
